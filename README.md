# IEEE Hyderabad Section — Team 2027 (campaign site)

A single, self-contained web page for the 2027 Officer Election team
(Negi · Muppalaneni · Gunjan · Saikumar Tara). All images are embedded,
so `index.html` is the only file needed to host it.

## Deploy on GitHub Pages
1. Create a new **public** repo (e.g. `ieee-hyd-team-2027`).
2. Add `index.html` to it (upload or `git push`).
3. Repo **Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save**.
4. After ~1 minute the site is live at
   `https://<your-username>.github.io/ieee-hyd-team-2027/`.

(For a root URL instead, name the repo `<your-username>.github.io`.)
